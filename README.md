# HESTIIA RESTAURANT — ADMIN DASHBOARD
**Client:** DIMISI Technologies  
**Project:** Hestiia Restaurant Administration System

---

## 🌟 Overview
Standalone React 19 + TypeScript + Vite + Tailwind CSS administration portal for Hestiia Restaurant management.

### Key Capabilities:
1. **Official Brand Logo Integration**: Brand badge on login screen, sidebar, invoice print receipts, and favicon.
2. **Dashboard Overview**: Live sales metrics, today's revenue, order preparation queue, and analytics charts.
3. **Menu Management**: Categorized dishes, real-time prices, dietary tags, and 86'd out-of-stock toggles.
4. **Orders & Kitchen Fulfillment**: Live pipeline from pending to confirmed, preparing, ready, and delivered.
5. **Customer Database**: Customer spending history, order count, and contact records.
6. **Payments & Digital Invoices**: Printable GST tax invoices with official restaurant branding.
7. **Table Reservations & Party Inquiries**: Moderation and booking confirmation.
8. **Ambience Gallery & Customer Reviews**: Photo manager and public review moderation.
9. **Restaurant Settings & Reports**: Tax rates, delivery charges, operational hours, and CSV export.

---

## 🚀 Running Locally

```bash
# 1. Install dependencies (if running standalone)
npm install

# 2. Start development server (Port 3000)
npm run dev
```

The dashboard will be available at:
👉 **[http://localhost:3000](http://localhost:3000)**
